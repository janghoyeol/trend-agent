# trend-agent

검색 급등을 **코드로 탐지**하고, 그 원인을 **뉴스 출처와 함께** 설명하는 에이전트.

## 흐름 (계획)

```
키워드 입력
  → [Gate] 성인 검색어 판별 (LLM 호출 전 무료 API로 필터)
  → 검색어트렌드 일별 추이 조회
  → 급등일 탐지 (코드, LLM 없음)
  → 급등일 전후 뉴스 매칭
  → Claude가 원인 후보를 기사 출처와 함께 설명
```

## 원칙

- 출처 없는 숫자는 쓰지 않는다.
- 계산(급등 탐지 등)은 모델이 아니라 코드가 한다.
- 원인이 알려진 급등 사례 정답셋으로 적중률을 측정한다.

## 사용 API (NAVER API HUB)

| API | 경로 | 상태 |
|---|---|---|
| 뉴스 검색 | `GET /search/v1/news` | 라이브 확인됨 |
| 검색어트렌드 | `POST /search-trend/v1/search` | 경로 확인, 스펙 확인 중 |
| 성인 검색어 판별 | `GET /search/v1/adult` | 경로 확인, 스펙 확인 중 |

## 알려진 제약

- 검색어트렌드는 절대 검색량이 아닌 상대지수(구간 최대 = 100).
- 뉴스 API에는 날짜 필터가 없고 `start` 상한이 1000이라, 최근 급등만 원인 매칭이 가능.
