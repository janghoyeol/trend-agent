# 0002. 급등 탐지: 중앙값/MAD z-score + 비율·최소지수 조건

- 상태: 채택 (2026-10-29). 임계값은 2단계 정답셋으로 재조정 예정.

## 맥락

- 검색어트렌드는 상대지수(구간 최대 = 100)이고, 저검색량 날은 응답에서 누락된다 (ADR 0001).
- 뉴스로 원인을 매칭할 수 있는 범위가 수 일이라 먼 과거의 급등은 설명할 수 없다.
- 탐지 결과의 모든 숫자는 출처(어떤 날짜의 어떤 값)를 댈 수 있어야 한다.

## 검토한 선택지

| 방식 | 기각/채택 이유 |
|---|---|
| A. 이동평균 + 표준편차 z-score | 0이 많으면 σ≈0 → 급등 남발, 과거 급등이 기준선을 끌어올림 → 기각 |
| B. 중앙값 + MAD z-score | 이상치에 강함 → **채택** (단독으로는 MAD=0 문제) |
| C. 기준선 대비 비율 + 최소 지수 | 직관적, 0 문제에 강함 → **B와 결합** |
| D. STL 계절성 분해 | 복잡·설명 어려움, 매칭 범위가 수 일이라 효용 작음 → 기각 |

## 결정

조회: 키워드 1개당 요청 1번(ADR 0001 스케일 문제), 최근 90일, 일 단위. 누락일은 0으로 채운다.

날짜 t마다 직전 28일(t-28..t-1)을 기준선으로:

- `median` = 기준선 중앙값, `MAD` = |x - median|의 중앙값
- `scale = max(1.4826·MAD, 0.1·median, 1.0)` — MAD=0일 때 0으로 나누지 않게 하한
- `z = (x_t - median) / scale`

다음을 **모두** 만족하면 급등일:

| 조건 | 기본값 | 의미 |
|---|---|---|
| `z ≥ 3.5` | 3.5 | Iglewicz–Hoaglin modified z-score 관례값 |
| `x_t ≥ 3 × median` (median=0이면 통과) | 3.0 | 체감되는 "급등" |
| `x_t ≥ 20` | 20 | 구간 최대의 20% 미만인 잔떨림 제외 |

- 연속된 급등일(사이 공백 1일까지 허용)은 **하나의 사건**으로 묶고, 최고값 날짜를 대표일로 삼는다.
- 기준선이 28일 미만인 앞부분은 판정하지 않는다.
- 관측일(누락 아닌 날)이 14일 미만이면 "데이터 부족"으로 반환하고 탐지하지 않는다. (저검색량 판정은 아래 보완 참조)

출력 예: "2026-10-23 상대지수 100 (직전 28일 중앙값 12.3 대비 8.1배, z=41.2)".

## 결과

- 계산은 전부 코드(`trend_agent/detect.py`), LLM 없음. 표준 라이브러리만 사용.
- 요일 주기 외 계절성(연말, 명절 등)은 무시한다. 오탐이 정답셋에서 문제되면 재검토.

## 보완 (2026-10-29 합의)

1. **같은 요일 기준선**: 직전 4주 같은 요일(t-7, t-14, t-21, t-28) 중앙값이 28일 중앙값의
   **1.5배 이상**이면 그것을 기준선으로 쓴다 (`baseline_kind = "same_weekday"`, 표기 "평소 토요일 대비").
   - 1.5배 마진이 없으면 주기 없는 키워드도 잡음 때문에 같은 요일 값(예: 6.417 vs 6.414)을 골라
     표기가 오해를 부름 → 마진 추가.
   - 대안 7일 이동평균은 하루짜리 급등과 날짜를 흐려서 기각.
2. **저검색량 판정**: 0이 아닌 지수의 서로 다른 값이 **20종류 미만**이면 `reason="low_volume"`으로
   탐지하지 않는다 (장호열 6종류 / 아이폰듀오 54 / 로또·태풍 90).
   - 대안 "관측일 50% 이상"은 아이폰듀오 같은 신조어 등장을 놓쳐서 기각.

재확인: 로또 → 급등 없음, 장호열 → 판단 불가(low_volume). 나머지 결과 동일.
로또 09-26(100, 평소 토요일 45 대비 2.2배)은 비율 조건 미달로 제외 — 실제 사건인지 정답셋에서 확인.
